# COPES Project Hub

A polished static landing page for GitHub Pages.

## Add your links

Open `index.html` and replace the three `href="#"` placeholders:

- Feedback form/document
- Chapter descriptions
- Slack workspace/channel

## Publish

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

The page is fully responsive and requires no JavaScript.
