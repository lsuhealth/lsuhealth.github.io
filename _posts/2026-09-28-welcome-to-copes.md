This blog will document the development of **COPES**, our AI-powered virtual-reality platform for clinical education and procedural training.

We will use this space to share:

- major platform milestones;
- research and evaluation updates;
- new clinical scenarios and procedures;
- technical integration notes across AI, VR, haptics, and analytics;
- selected lessons learned from building the platform.

Because the website uses **Jekyll**, every blog post is simply a Markdown file stored in the `_posts` directory.

## Writing a new post

Create a new file using this naming format:

`YYYY-MM-DD-title-of-the-post.md`

Then add front matter at the top:

```yaml
---
title: "Your Post Title"
date: 2026-10-01
author: "Your Name"
category: "Research"
excerpt_text: "One-sentence summary of the post."
---
```

Everything below the front matter can be written in normal Markdown.
